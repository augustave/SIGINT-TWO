# Pattern Card — Confidence Stipple

> **Texture is meaning.** Stipple grain encodes how much the operator should trust the underlying source.
> Higher density = lower confidence.

## Mapping

| `provenance_class` | Visual | Operator should infer |
|---|---|---|
| `high_res_lidar` | <img src="../patterns/confidence_stipple_high_res_lidar.svg" width="160"/> | Trust the surface. Use for fine-grained measurements. |
| `medium_confidence` | <img src="../patterns/confidence_stipple_medium_confidence.svg" width="160"/> | Surface is reasonable but not authoritative. |
| `interpolated` | <img src="../patterns/confidence_stipple_interpolated.svg" width="160"/> | Filled-in data. Don't measure to centimeters. |
| `synthetic` | <img src="../patterns/confidence_stipple_synthetic.svg" width="160"/> | Generated, not observed. Treat as approximation only. |

## Doctrine rules

- Stipple is rendered as **layer 4** in the canonical stack (blend: `screen`).
- **Missing provenance** must default to `medium_confidence` grain **plus** a degraded-state warning badge — never silently downgraded to invisible.
- Synthetic and interpolated grain **must increase**, never decrease, when budget is tight. (Suppress the layer entirely under field-tablet performance pressure rather than silently lowering grain.)
- Stipple is the **first** layer dropped in the field-tablet performance ladder. When dropped, the manifest must include `REDUCED_SEMANTIC_FIDELITY`.
